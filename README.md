# 📦 Projeto Web - Sistema de Estoque de Supermercado

Este projeto foi desenvolvido como requisito parcial para aprovação na disciplina *Desenvolvimento para Web, do curso de **Análise e Desenvolvimento de Sistemas* da *Universidade Federal do Cariri*.

O sistema de estoque foi estruturado com *HTML, CSS e JavaScript*, seguindo boas práticas de desenvolvimento.

## 🚀 Tecnologias Utilizadas
- *HTML5*
- *CSS3*
- *JavaScript (ES6+)*
- *Node.js* e *npm* para gerenciamento de dependências
- *GitHub Actions* para Integração Contínua (CI)

---

## 📋 Pré-requisitos
Para executar o projeto localmente, é necessário ter instalado:
- [Node.js](https://nodejs.org/) (inclui o npm)

---

## ⚙️ Como Executar o Projeto

```bash
# Clone o repositório
git clone https://github.com/WelaineDantas/sistema_mercado.git

# Acesse o diretório
cd sistema_mercado

# Instale as dependências
npm install

# Executa testes localmente
npm run lint:js
